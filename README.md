# Skyrianos

A visual guide to the island of Skyros, Greece: its beaches, food, sights, history and the Skyrian
Carnival, as a single-page website.

The site was online at skyrianos.com and is no longer hosted; the code and images in
this repository are the complete site.

## Features

- Sections for the beaches, the local food, the sights, the history of the island and the Carnival
- Pop-ups with a photo and a description for each beach, dish and sight
- Animations and image transitions
- Responsive layout for desktop and mobile
- Search-engine metadata and a sitemap

## Technologies

HTML5, CSS3 and vanilla JavaScript, with Google Fonts; no build step. It was deployed on Netlify from
this repository.

## Viewing it

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 8000      # then open http://localhost:8000
```
